# Challenge a Repeatedly Failing Premise

Use when prior attempted fixes sharing one premise repeatedly fail.

Name that premise and the observation that would disprove it before proposing another fix under the same assumption. Preserve the failed attempts as evidence only where they change the next investigation.

Compare what the failed attempts held constant with what they changed. Find the smallest observation that separates the shared premise from a competing explanation, obtain it, and use the result to choose the next hypothesis. If the same failure persists despite different treatments, adding another treatment does not establish that the underlying model is right.

For an uneven resource or work distribution, measure it per actor rather than only in aggregate. If the same actors repeatedly carry the cost, inspect how that role is assigned before adding compensation. This is one diagnostic example, not a requirement to count actors for every kind of failure. A result that supports the premise should keep it in consideration; repeated failure alone does not prove it false.
